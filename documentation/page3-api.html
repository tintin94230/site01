Page 3 – API & base de données

1. Principe général

Les API servent d’intermédiaire entre le site HTML et Supabase. Elles protègent les clés et centralisent la logique.

2. API /api/supabase001

API utilisée par blog.html.

Fonctions :

  • Ajouter un mot
  • Calculer sa longueur
  • Stocker le mot dans la base

Exemple :

/api/supabase001?mot=bonjour

3. API /api/supabase002

API prévue pour admin.html.

  • Gestion avancée des données
  • Accès réservé côté serveur

4. Base de données Supabase

Table : mots

  • id
  • mot
  • created_at

5. Sécurité

Les clés Supabase ne sont jamais exposées dans le HTML. Elles sont stockées uniquement dans Vercel ou .env.local.

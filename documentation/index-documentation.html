🔄 Quick Restart – Checklist de vérification

1️⃣ Vérifier la production (PROD)

  • Ouvrir l’URL publique Vercel : https://site01-snowy.vercel.app/
  • Vérifier que la page d’accueil s’affiche
  • Tester blog.html
  • Tester admin-lieux.html

Test API PROD :

https://site01-snowy.vercel.app/api/supabase001?mot=test

Si une réponse JSON apparaît → API PROD fonctionnelle.

2️⃣ Vérifier l’environnement local (DEV)

Lancer le projet :

npm install
npm run dev

Ouvrir ensuite :

http://localhost:3000

Test API DEV :

http://localhost:3000/api/supabase001?mot=test

Si une réponse apparaît → API DEV fonctionnelle.

3️⃣ Vérifier Supabase

  • Se connecter au dashboard Supabase
  • Ouvrir la table mots
  • Vérifier qu’un nouvel enregistrement apparaît après test

4️⃣ Vérifier les variables d’environnement

En local :

  • Fichier .env.local présent
  • Variables définies : SUPABASE_URL, SUPABASE_KEY

En production :

  • Vérifier les variables dans le dashboard Vercel

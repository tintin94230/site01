1️⃣ Présentation générale

Le projet tintin94230-page-test est un site expérimental pour tester et comprendre :

  • Développement Front-end (HTML, CSS, JavaScript)
  • Création d’API backend (Node.js / Serverless)
  • Utilisation d’une base de données cloud (Supabase)
  • Appel d’APIs externes (OpenWeatherMap, SNCF)
  • Versioning Git (GitHub)
  • Déploiement moderne (Vercel)

3️⃣ Structure HTML et navigation

Toutes les pages partagent la même structure :

  • Header avec titre et description
  • Menu de navigation horizontal
  • Main avec contenu spécifique
  • Footer avec signature
<header>
  <h1>Titre</h1>
  <p>Description</p>
</header>
<nav>
  <ul>
    <li><a href="index.html">Accueil</a></li>
    ...
  </ul>
</nav>
<main>...</main>
<footer>© 2026</footer>

4️⃣ Style et design

Principes :

  • Typographie : Inter
  • Palette claire / moderne
  • Navigation horizontale avec hover
  • Responsive de base

5️⃣ Évolutions possibles

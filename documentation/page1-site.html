Page 1 – Le site web

Cette page décrit l’ensemble du site, ses pages HTML, ses rôles et les APIs consommées. Elle sert de référence pour comprendre l’architecture front-end.

1️⃣ Présentation générale

Le projet tintin94230-page-test est un site web statique (HTML / CSS / JS) avec APIs backend serverless et base cloud Supabase. L’hébergement est effectué sur Vercel et les pages HTML consomment des APIs internes ou publiques selon les besoins.

  • Front-end : HTML / CSS / JavaScript
  • Backend : Node.js serverless sur Vercel
  • Base de données : Supabase (PostgreSQL cloud)
  • APIs externes : météo, géocodage
  • Workflow : DEV local → Preview → PROD

2️⃣ Pages du site et rôles

Les fichiers HTML se trouvent dans /public :

Page Rôle API consommée
index.html Page d’accueil et navigation principale Aucune
apropos.html Présentation du projet Aucune
projets.html Tests d’APIs publiques API météo (frontend)
blog.html Page dynamique connectée à Supabase /api/supabase001
admin.html Administration (future) /api/supabase002
admin-lieux.html Gestion de lieux géographiques /api/supabase002 + API géocodage
admin-pays.html Gestion de pays (CRUD, export CSV) /api/supabasePays
admin-infopays.html Informations détaillées par pays /api/supabaseInfoPays (future)

3️⃣ APIs consommées

3.1 Internes

  • /api/supabase001 → blog.html
  • /api/supabase002 → admin.html, admin-lieux.html
  • /api/supabasePays → admin-pays.html
  • /api/supabaseInfoPays → admin-infopays.html (à venir)

3.2 Externes publiques

4️⃣ Architecture générale

Important : Aucune page HTML n’accède directement à la base de données.

Navigateur (HTML / JS) | v API backend (Vercel) | v Base de données (Supabase)

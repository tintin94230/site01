1️⃣ Présentation générale

Le projet tintin94230-page-test est un site web statique (HTML / CSS / JavaScript) hébergé sur Vercel.

  • Front-end HTML / CSS / JavaScript
  • APIs backend serverless (Node.js)
  • Base de données cloud Supabase
  • APIs externes publiques (météo, géocodage)
  • Déploiement moderne DEV → PROD

2️⃣ Pages du site et rôles

Les pages HTML du site sont situées dans le dossier /public.

Page Rôle API consommée
index.html Page d’accueil et navigation principale Aucune
apropos.html Présentation du projet Aucune
projets.html Tests d’APIs publiques API météo (frontend)
blog.html Page dynamique connectée à la base /api/supabase001
contact.html Page de contact Aucune
admin.html Administration (future) /api/supabase002
admin-lieux.html Gestion de lieux géographiques /api/supabase002
API de géocodage

3️⃣ APIs consommées par le site

3.1 APIs internes (backend du projet)

  • /api/supabase001 – utilisée par blog.html
  • /api/supabase002 – utilisée par admin.html et admin-lieux.html

👉 Voir Page 3 – API & base de données

3.2 APIs externes publiques

🌦️ API météo

Utilisée par projets.html pour tester les appels fetch() côté navigateur.

📚 Documentation : https://openweathermap.org/api

🗺️ API de géocodage (Nominatim / OpenStreetMap)

Utilisée par admin-lieux.html pour convertir un nom de lieu en coordonnées GPS (latitude / longitude). 

https://nominatim.openstreetmap.org/search

📚 Documentation : https://nominatim.org/release-docs/latest/api/Search/

projets.html ──► API météo (publique) admin-lieux.html ──► API Nominatim | └──► /api/supabase002 ──► Supabase

4️⃣ Principe fondamental d’architecture

Aucune page HTML n’accède directement à la base de données.

Navigateur (HTML / JS) | v API backend (Vercel) | v Base de données (Supabase)

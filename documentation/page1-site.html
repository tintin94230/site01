Page 1 – Le site web

1. Présentation générale

Le site est un site web statique (HTML / CSS / JavaScript) hébergé sur Vercel. Certaines pages sont purement informatives, d’autres interagissent avec des API.

2. Pages du site et rôles

index.html

Page d’accueil et navigation principale. Ne consomme aucune API.

apropos.html

Présentation du projet et de sa démarche. Ne consomme aucune API.

projets.html

Page de tests d’API publiques (exemples : météo, transports, etc.). Ces API sont appelées directement depuis le navigateur.

blog.html

Page dynamique connectée à la base de données via une API interne.

API consommée : /api/supabase001 Voir Page 3 – API

contact.html

Page de contact. Ne consomme aucune API.

admin.html

Zone d’administration (évolution future).

API prévue : /api/supabase002 Voir Page 3 – API

3. Principe fondamental

Aucune page HTML n’accède directement à la base de données. Toute communication passe par des API backend sécurisées.

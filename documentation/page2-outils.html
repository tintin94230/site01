Page 2 – Outils & déploiement

1. Outils utilisés

  • Visual Studio Code – écriture du code
  • Git – gestion des versions
  • GitHub – hébergement du dépôt
  • Vercel – hébergement du site et des API
  • Supabase – base de données PostgreSQL
  • OVH – nom de domaine

2. Environnements

Local (développement)

  • Serveur local
  • Variables dans .env.local
  • Fichier non versionné

Production

  • Variables stockées dans Vercel
  • Aucun fichier .env.local en ligne

3. Tests

Les API sont testées :

  • via le navigateur
  • via fetch()
  • via l’interface Supabase

4. Déploiement

git push
vercel --prod

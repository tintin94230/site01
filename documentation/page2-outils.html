Page 2 – Outils, workflow & déploiement

Cette page décrit le cycle complet de développement du projet : édition du code, tests locaux, gestion Git, déploiement sur Vercel et exposition publique via un nom de domaine OVH.

1️⃣ Outils utilisés

  • Visual Studio Code – éditeur de code principal
  • Git – gestion des versions
  • GitHub – hébergement du code source
  • Vercel – déploiement du site et des API serverless
  • Supabase – base de données PostgreSQL cloud
  • OVH – gestion du nom de domaine

⚠️ Important :

  • 📦 Le code source est versionné sur GitHub
  • 🌍 Le site (HTML + API) est déployé sur Vercel

2️⃣ Visual Studio Code

Rôle

Visual Studio Code est utilisé pour écrire, modifier et organiser les fichiers HTML, CSS, JavaScript et API Node.js.

Extensions recommandées (HTML / Web)

  • Live Server – aperçu rapide du HTML
  • Prettier – formatage automatique du code
  • HTML CSS Support – autocomplétion
  • Auto Rename Tag – renomme les balises liées
  • ESLint – détection d’erreurs JavaScript

Terminal intégré

VS Code intègre un terminal permettant d’exécuter des commandes Bash / Git / Node.js sans quitter l’éditeur.

Exemples :

git status
git commit -m "Mise à jour page projets"
npm run dev
vercel --prod

👉 Sous Windows, le terminal peut être :

  • Bash (Git Bash)
  • PowerShell
  • WSL

3️⃣ Environnements

Développement local (DEV)

  • Site lancé sur localhost
  • Variables stockées dans .env.local
  • Fichier jamais versionné

Production (PROD)

  • Site déployé sur Vercel
  • API serverless exécutées sur Vercel
  • Variables configurées dans l’interface Vercel
  • URL publique : https://site01-snowy.vercel.app/

4️⃣ Nom de domaine & OVH

Le nom de domaine est géré via l’interface OVH :

https://manager.eu.ovhcloud.com/#/hub/

Rôle réel d’OVH

  • Gestion DNS
  • Redirection vers Vercel
  • Aucun hébergement du site lui-même

Flux réel : 

Navigateur
   |
   v
Nom de domaine (OVH)
   |
   v
Site déployé sur Vercel
   |
   v
APIs / Base Supabase

👉 OVH agit comme une porte d’entrée DNS, Vercel comme la plateforme d’hébergement.

5️⃣ Workflow de développement

1. Modifier le code

Développement local dans Visual Studio Code.

2. Tester en local

Site HTML simple

npx serve .

Projet avec API

npm install
npm run dev

3. Arrêter le serveur

CTRL + C

6️⃣ Sauvegarde du code avec Git

Workflow standard

git status
git add .
git commit -m "Description claire"
git push

Le dépôt GitHub devient la source de vérité du projet.

7️⃣ Déploiement avec Vercel

Preview

vercel

Production

vercel --prod

Le déploiement est automatique et atomique.

8️⃣ Variables d’environnement

Les variables sont définies dans Vercel selon l’environnement (DEV / PREVIEW / PROD). 

SUPABASE_URL
SUPABASE_KEY

Chargement local : 

vercel env pull

9️⃣ Résumé

  • Code versionné sur GitHub
  • Site et API déployés sur Vercel
  • OVH gère uniquement le DNS
  • VS Code est l’outil central
  • Workflow simple, clair et reproductible

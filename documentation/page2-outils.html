Page 2 – Outils, workflow & déploiement (v3)

Cette page décrit le cycle complet de développement : édition du code, tests locaux, gestion Git, déploiement sur Vercel, connexion Supabase, nom de domaine OVH, et gestion des nouvelles APIs de pays.

1️⃣ Outils utilisés

  • Visual Studio Code – éditeur principal
  • Git / GitHub – gestion de versions et hébergement du code
  • Vercel – déploiement du site et APIs serverless
  • Supabase – base de données PostgreSQL cloud
  • OVH – gestion DNS / nom de domaine
  • Node.js & npm – exécution serveur / scripts

2️⃣ Visual Studio Code

Rôle

Édition, navigation et organisation du projet (HTML, CSS, JS, API Node.js).

Extensions recommandées

  • Live Server – aperçu HTML instantané
  • Prettier – formatage automatique
  • HTML CSS Support – autocomplétion CSS
  • Auto Rename Tag – renomme les balises liées
  • ESLint – détection d’erreurs JS

Terminal intégré

VS Code permet d’exécuter :

npm install
npm run dev
git status
git commit -m "Message"
vercel --prod

3️⃣ Environnements DEV / PROD

3.1 Développement local (DEV)

  • Site sur localhost:3000
  • Variables stockées dans .env.local (jamais versionnées)
  • Lancer serveur : npm run dev
  • Arrêter serveur : CTRL + C

3.2 Production (PROD)

  • Site et APIs déployés sur Vercel
  • Variables configurées dans Vercel (Environment Variables)
  • URL publique : https://site01-snowy.vercel.app/

3.3 Nouvelles APIs liées aux pays

  • /api/supabasePays → Gestion CRUD des pays, export CSV
  • /api/supabaseInfoPays → Gestion des infos détaillées par pays (table infos_pays)
  • Intégration prévue dans les pages admin-pays.html et admin-infopays.html
  • DEV et PROD séparés pour sécurité

4️⃣ OVH – Gestion du nom de domaine

OVH sert uniquement de porte DNS :

Navigateur
   |
   v
Nom de domaine OVH
   |
   v
Site déployé sur Vercel
   |
   v
APIs / Base Supabase

Actions courantes OVH

  • Redirection DNS vers Vercel
  • Gestion des sous-domaines
  • Aucun hébergement direct du site

5️⃣ Workflow complet – DEV → PROD

5.1 Modifier le code

Éditer HTML, CSS, JS, APIs dans VS Code.

5.2 Tester en local

  • Site simple HTML : npx serve .
  • Projet avec API : npm install puis npm run dev

5.3 Arrêter le serveur

CTRL + C

5.4 Git – Sauvegarde / Versionning

Commandes usuelles :

git status
git add .
git commit -m "Description claire"
git push

Le dépôt GitHub est la source de vérité.

5.5 Déploiement Vercel

  • Preview : vercel
  • Production : vercel --prod
  • Synchroniser variables d’environnement : vercel env pull
  • Déploiement des nouvelles APIs : /api/supabasePays et /api/supabaseInfoPays

6️⃣ Variables d’environnement

DEV :

.env.local
SUPABASE_URL
SUPABASE_KEY

PROD : configurées dans Vercel → Dashboard → Environment Variables

7️⃣ Résumé – Récupération rapide

  • VS Code pour éditer / tester
  • GitHub pour versionner
  • Vercel pour déployer site et APIs
  • OVH pour DNS / nom de domaine
  • Supabase pour base de données
  • Workflow simple : Modifier → Tester DEV → Commit Git → Déployer PROD
  • Nouvelle API supabasePays et future supabaseInfoPays intégrées au workflow
